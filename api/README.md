# apimock.codes API

Go backend API with dynamic route registration from JSON schemas.

## Development

```bash
go run main.go
```

Server runs on http://localhost:8080

## Stack

- Go 1.22+
- Gin v1.11.0
- gofakeit/v7
- CORS enabled
